# Приложение для анализа банковских операций из выгрузки Excel-файла
>Приложение анализирует банковские операции из Excel-выгрузки и возвращает
результат в формате JSON, готовом для отображения на веб-странице.

>Исходные данные берутся из `data/operations.xlsx` — дата, сумма, категория,
номер карты и описание каждой операции. Курсы валют и котировки акций
подтягиваются из внешних API по списку из `user_settings.json`.
## Что реализовано:
1. Страница «Главная» — JSON-ответ с приветствием, картами, топ-5 транзакций, курсами и акциями
2. Сервис «Простой поиск» — поиск по описанию и категории, без учёта регистра
3. Отчёт «Траты по категории» — траты за последние три месяца, с сохранением в файл

### Установка:
1. Клонировать `git clone https://github.com/vvoloshin77/CW-1.git`
2. `poetry install`
3. Создать `.env` по образцу `.env_template` и вписать два ключа

### Запуск 
```bash
poetry run python -m src.main
```

### Пример использования

Главная функция принимает дату и время в формате `YYYY-MM-DD HH:MM:SS`
и возвращает JSON-ответ со сводкой за период с начала месяца по указанную дату.

```python
from src.views import main_page

print(main_page('2021-12-31 16:44:00'))
```
